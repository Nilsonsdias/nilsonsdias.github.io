# Gestão NEAD · Univel

Interface de homologação: https://nilsonsdias.github.io/

Os dados exigem login e autorização institucional. O botão Google usa OAuth/PKCE e preserva os perfis existentes. Login Google ativado e validado em 22/10/2026 com a conta institucional previamente autorizada; o login com senha permanece disponível. A identidade Google não concede acesso automaticamente aos módulos.

Esta distribuição estática corresponde ao commit def30664e81a0bc6ed43882493df51bed1e181b9 do repositório privado de desenvolvimento. Sem dados reais ou credenciais privadas. Não substitui o Apps Script operacional.

O administrador pode pré-cadastrar e-mails, perfis e permissões em Administração → Usuários e acessos, antes do primeiro login. O cadastro não cria senha nem envia convite.
